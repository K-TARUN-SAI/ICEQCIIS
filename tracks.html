Conference Tracks

Submissions are invited in the following tracks (but not limited to):

Track 1: Quantum Computing & Communication

  • Quantum Algorithms and Architectures
  • Quantum Communication Networks
  • Quantum Key Distribution (QKD)
  • Post-Quantum Cryptography
  • Quantum Machine Learning

Track 2: IoT & Smart Systems

  • Secure IoT Architectures
  • Edge, Fog, and Cloud-IoT Integration
  • Industrial IoT (IIoT)
  • Smart Cities and Smart Infrastructure
  • Wearable and Healthcare IoT
  • Signal Processing for IoT

Track 3: AI & Intelligent Systems

  • Machine learning for intelligent decision support
  • AI-driven anomaly and threat detection
  • Deep learning for IoT security
  • Cognitive computing and automation
  • AI in Bioinformatics & Semiconductor Devices
  • Natural Language Processing

Track 4: Secure Communication

  • Secure 5G/6G Networks
  • SDN Security
  • Wireless Sensor Network Security
  • Quantum networks and communications
  • Cloud Communications and Networking

Track 5: Math Foundations

  • Applied Mathematics for Engineering
  • Cryptographic Algorithms
  • Optimization Techniques
  • Statistical Modeling
  • Graph Theory and Network Analysis
